# جیبیتو

اپ اندرویدی ثبت خودکار خرج از روی پیامک بانک — Kotlin + Jetpack Compose.

## طرح
ظاهر اپ طرح «جیبی» است: رنگ‌ها، اندازه‌ها، آیکون‌های خطی و لحن متن‌ها از ماکاپ‌های طراحی آمده‌اند.
- توکن‌های رنگ: `ui/theme/Theme.kt` (قرمز فقط هشدار، سبز فقط «پول اومد»، فیروزه‌ای برای حال خوب)
- رنگ و آیکون دسته‌ها: `ui/theme/CategoryStyle.kt`، آیکون‌های خطی: `ui/theme/DesignIcons.kt`
- جیبی (شخصیت اپ) و اجزای مشترک: `ui/common/DesignParts.kt`

## ساخت APK
هر بار که کدی به شاخه‌ی `main` اضافه شود، GitHub Actions خودکار APK را می‌سازد:
تب **Actions** ← آخرین اجرا ← بخش **Artifacts** ← `jibito-apk`.

## اسکرین‌شات‌ها
تصویرهای مرجع صفحه‌های اصلی (هر سه پوسته، روشن و تیره، و با فونت بزرگ) در `app/src/test/screenshots/` هستند.
CI در هر اجرا ظاهر را با آن‌ها مقایسه می‌کند و اگر چیزی عوض شده باشد قرمز می‌شود؛ تصویر تفاوت‌ها در Artifact `screenshots` است.
بعد از تغییر عمدی ظاهر: تب **Actions** ← **Build APK** ← **Run workflow** روی همان شاخه، با تیک `record_screenshots`.
تصویرهای تازه خودکار در شاخه ذخیره می‌شوند.

ساخت روی کامپیوتر: `./gradlew testDebugUnitTest assembleDebug` (نسخه‌ی Gradle و همه‌ی کتابخانه‌ها در `gradle/` ثابت شده‌اند).
