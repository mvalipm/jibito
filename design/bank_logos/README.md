# لوگوی بانک‌ها (بازطراحی)

۲۷ لوگوی بانک، بازطراحی‌شده با فرم اصلی و رنگ سازمانی هر بانک، با پس‌زمینه‌ی شفاف.

- `svg/` — نسخه‌ی برداری، بوم ۵۱۲×۵۱۲
- `png/` — خروجی ۵۱۲×۵۱۲ با پس‌زمینه‌ی شفاف
- `vector_xml/` — Vector Drawable اندروید (۴۸dp، گرادیان‌ها با `aapt:attr`، نیاز به API 24+)
- `preview.png` — مقایسه: اصلی / جدید روی زمینه‌ی روشن / جدید روی زمینه‌ی تیره

سبک: فرم هر نشانه بدون تغییر و فقط با گوشه‌های کمی نرم‌شده؛ رنگ‌های تخت به گرادیان هم‌رنگِ سازمانی تبدیل شده‌اند؛
یک لایه‌ی براقِ ملایم روی هر شکل؛ همه در مرکز و با اندازه‌ی یکسان روی بوم.
در سپه، تجارت و خاورمیانه بدنه‌ی سفیدِ نشان (که در فایل‌های اصلی شفاف بود) اضافه شده تا روی تم تیره هم درست دیده شوند.
